| F-005 | Spec-14 L5 canary anti-exfiltration guard false-positives on ordinary verbose Bedrock responses. **Investigated, root-caused, and CLOSED (2026-07-13)** — policy decided, fix shipped. Root cause (confirmed via real-Bedrock trials, aws agent, `us.anthropic.claude-sonnet-4-5`, temp 0.1, original unfixed code): the model has a learned prior toward appending a "Session:"/"Trace:"/"Reference:" footer to "professional" technical answers, and grabs the canary token (the only opaque-hex-shaped value in context) to fill it — pure helpfulness, no injection or malicious intent. Two format mitigations attempted: (1) an explicit "never repeat this value" clause placed *inside* the marker text did nothing (the model treats `<infra_data>` content as inert DATA per the anti-injection framing, so an instruction embedded there is also just data — self-defeating); (2) reformatted the marker from a labeled field (`[session-ref: TOKEN]`) to an HTML-comment annotation (`<!-- internal-telemetry-id, do not output: TOKEN -->`) plus a system-level (outside `<infra_data>`) instruction — 0/14 leaks in the final correctly-instrumented live trials (earlier "25%→13%" figures reported mid-session were **retracted**: those comparison runs used a stale Docker image that predated the code edits under test, so they weren't actually measuring the fix — caught and corrected before this entry was closed). **Policy decision (asked the user directly, chose B): redact-and-continue, not hard-block.** `CanaryGuard.detect()` now returns the response with any leaked token replaced by `[redacted]` (audit log still fires — the signal isn't lost) instead of raising `GuardrailBlockedError` — a deliberate, informed deviation from spec-14's fail-closed default for this one layer specifically: the token is single-use and worthless once redacted, so denying an otherwise-legitimate answer on a benign false positive cost more than it protected. `src/core/canary.py`, `src/core/generic_agent.py` (return value now threaded through). Tests: `tests/test_canary.py` (rewritten `TestDetectLeak`/`TestFuzzyDetection`/etc. for the new redact contract + `test_marker_is_html_comment_style_not_a_labeled_field` + `test_prefix_residue_also_redacted`), `tests/test_canary_output_integration.py` (rewritten `TestIntegrationCanaryLeak`), `tests/test_generic_agent.py::TestCanaryMarkerNonRepetitionInstruction`. Full suite: 700 passed / 94.25% cov, lint clean. `AGENTS.md` invariant #6 and `docs/SECURITY.md` §S4 L5 description updated same day to document the exception | ✅ CLOSED | fixed |
